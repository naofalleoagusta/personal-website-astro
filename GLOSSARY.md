# Naofal Leo Agusta — Personal Site

A personal website presented as a code editor: visitors browse the site the way a developer browses a project.

## Language

**Workspace**:
The full editor-shaped frame that surrounds every page and stays put while the visitor moves between Files.
_Avoid_: Shell, IDE, layout, chrome

**File**:
One addressable piece of the site, shown to the visitor as if it were a file in the Workspace. Every File has its own URL.
_Avoid_: Page, screen, view, section

**Folder**:
A File that groups other Files and is shown as a listing of them (e.g. the blog).
_Avoid_: Directory, index, archive

**Explorer**:
The tree of every File and Folder in the Workspace; the primary way to move around the site.
_Avoid_: Sidebar, nav, menu

**Tab**:
A File the visitor has opened during their visit, kept within reach until they close it.
_Avoid_: Open file, history

**Preview**:
How a Markdown File is shown: rendered as readable prose rather than as source.
_Avoid_: Rendered view, reader mode

**Terminal**:
A text prompt in the Workspace where the visitor types commands to move around or change settings.
_Avoid_: Console, shell, CLI

**Command Palette**:
A keyboard-summoned search for jumping to any File or running an action.
_Avoid_: Quick open, search, spotlight

**Status Bar**:
The strip at the bottom of the Workspace showing facts about the current File and the site.
_Avoid_: Footer

**Theme**:
A named colour scheme for the Workspace that the visitor can switch between.
_Avoid_: Mode, skin, light/dark mode
